# BloxyMart - Roblox Avatar Downloader

🎮 **BloxyMart** es una herramienta web para descargar información de avatares de Roblox y generar modelos OBJ básicos.

## 🌟 Características

- ✅ Buscar usuarios de Roblox por nombre de usuario
- ✅ Ver previa del avatar (imagen 420x420)
- ✅ Obtener información del perfil (Usuario, Display Name, User ID)
- ✅ Generar archivo OBJ básico del avatar
- ✅ Ver datos JSON de la respuesta de la API
- ✅ Interfaz oscura moderna
- ✅ Totalmente responsiva

## 🚀 Uso

1. Accede a: **https://KaltaOficial.github.io/BloxyMart**
2. Escribe el nombre de usuario de Roblox
3. Haz clic en **Buscar**
4. Descarga el archivo `.OBJ` si lo necesitas

## 📝 Requisitos

- Navegador moderno con soporte para Fetch API
- Conexión a internet

## 🔧 Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- APIs públicas de Roblox
